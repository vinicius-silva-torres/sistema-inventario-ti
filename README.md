Sistema de Inventário de TI

📋 Sobre o projeto

O Sistema de Inventário de TI é uma aplicação web desenvolvida para auxiliar no gerenciamento e controle de ativos de tecnologia.

O projeto tem como objetivo facilitar o cadastro, a organização e a consulta de equipamentos de TI, além de servir como projeto de portfólio para demonstrar meus conhecimentos em desenvolvimento web e integração entre frontend, backend e banco de dados.

🚀 Funcionalidades

Cadastro de equipamentos

Consulta de equipamentos cadastrados

Busca de equipamentos por patrimônio, marca ou modelo

Filtros para facilitar a localização de ativos

Gerenciamento das informações dos equipamentos

🛠️ Tecnologias utilizadas

Frontend

HTML5

CSS3

JavaScript

Backend

Node.js

Express.js

Banco de dados

MySQL

⚙️ Como executar o projeto

Pré-requisitos

Node.js

npm

MySQL

Instalação

Clone o repositório:

git clone URL_DO_REPOSITORIO

Entre na pasta do projeto:

cd sistema-inventario-ti

Instale as dependências:

npm install

Configure a conexão com o banco de dados MySQL.

Inicie o servidor:

node src/server.js
